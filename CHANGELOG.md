# История изменений

Формат: новые версии сверху. Версия расширения и версия помощника (`HOST_VERSION`) меняются независимо: если помощник обновился, это сказано отдельно.

## [1.7.1]
- **MP3 теперь скачивается как настоящий MP3:** имя файла без технического `[id]`, лучшее качество, название и автор в тегах. Если ffmpeg не найден, программа сразу скажет об этом, а не оставит непонятный файл.
- Кнопка на YouTube пишет «Скачивание началось», а когда файл готов — «Скачано · имя файла».
- Вкладка «Загрузки»: готовые видео остаются на 30 секунд с кнопками «Открыть файл» и «Показать в папке», ошибки не пропадают сразу.
- Кнопка на YouTube сама показывает «Скачиваю 45%» и превращается в «Скачано» только когда файл готов.
- В истории три действия: «Показать в папке», «Копировать ссылку», удалить.
- Выровнены вкладки и кнопки, на главном экране есть подсказка про ffmpeg для MP3.
- **Помощник обновился (v10):** закройте Firefox → `install\update.ps1` → `install\sign.ps1` → установите новый `.xpi`.

## [1.7.0]
- Во весь экран кнопки нет совсем: ни в ряду YouTube, ни плавающей (она мешала просмотру). После выхода из полного экрана кнопка сама возвращается на место.
- Shorts: исправлена настоящая причина сбоя с комментариями (кнопка могла вставиться в сам список комментариев); кнопка больше не пропадает «просто так».
- Новая вкладка «Настройки → Скорость»: потоки на загрузку, лимит скорости, одновременные загрузки. Помощник сам включает Node.js для расшифровки YouTube, если нет Deno.
- Окно расширения подстраивается под размер: узкое окно, широкое отдельное окно.
- **Помощник обновился (v9):** закройте Firefox → `install\update.ps1` → `install\sign.ps1` → установите новый `.xpi`.

## [1.5.0]

## [1.4] — плейлисты как сборник, панель и Shorts
- **Плейлист одним нажатием.** Кнопка «Скачать плейлист» на странице плейлиста (и горячая клавиша, и меню «Скачать сразу») скачивает весь плейлист по быстрым настройкам: либо **одним MP4-сборником**, либо отдельными файлами в папке с названием плейлиста — переключатель «Плейлист одним нажатием» в «Настройках» и в панели кнопки (правый клик или стрелка).
- **Как делается сборник:** ролики скачиваются параллельно, каждый приводится к единому формату (кадр 1080/720/480p по выбранному качеству, 30 к/с, H.264 + AAC), затем склеиваются без перекодирования; в файл добавляются **главы по названиям роликов**. Для MP3 получается один MP3. Нужен **ffmpeg** (`winget install Gyan.FFmpeg`; путь можно указать в «Настройках»). Ролики, которые не скачались или не обработались, пропускаются, остальное склеивается.
- **Большие плейлисты:** больше 40 роликов или 4 часов — сначала спрашивает подтверждение. Не больше 300 роликов за раз.
- **Списки «Понравившиеся» (`LL`), «Смотреть позже» (`WL`)** работают: для них всегда используются cookies Firefox.
- Панель быстрых настроек закрывается как открылась: повторный клик по стрелке, клик мимо, Esc, прокрутка, смена размера окна. В Shorts кнопка встаёт под «Поделиться» с теми же интервалами, что у родных кнопок.
- Окно расширения: плейлист со страницы YouTube сразу открывает выбор роликов; запись сборника в истории («Повторно» пересобирает его).

Обновление: помощник изменился (v10) → закройте Firefox → `update.ps1` → `sign.ps1` → установите новый `.xpi`.
Временные файлы сборника лежат в скрытой папке `.ytdl_tmp_…` внутри папки загрузки и удаляются сами; если Firefox закрыли посреди сборки, папку можно удалить вручную.

## [1.3.1] — кнопка на YouTube подстраивается под страницу
Кнопка считывает реальный вид соседних кнопок (высота, скругление, фон, цвет, шрифт) и повторяет его, поэтому одинаково выглядит в светлой и тёмной темах. Место для неё ищется по геометрии, а не по названиям элементов YouTube:
- **видео** — в ряд кнопок под плеером, той же высоты;
- **Shorts** — в колонку круглых кнопок прямо под «Поделиться», с таким же размером, интервалом и подписью;
- **плейлист** — под рядом «Воспроизвести все / Перемешать», на всю его ширину.
Если подходящего места нет, через 2,5 секунды появляется плавающая кнопка в правом нижнем углу.
Обновление: помощник не менялся (v7), достаточно `sign.ps1` и установки нового `.xpi`. Для быстрой проверки без подписи: `about:debugging` → «Загрузить временное дополнение».

## [1.3] — кнопка на YouTube, горячая клавиша, очередь
- **Кнопка «Скачать» прямо на YouTube** (под видео, в колонке кнопок Shorts, в шапке плейлиста). Если YouTube изменит вёрстку и место для кнопки не найдётся, через 2,5 секунды появится плавающая кнопка в углу страницы.
- **Скачать одним нажатием.** При первом нажатии откроется окно выбора (cookies, качество), и оно запомнится. Дальше кнопка, горячая клавиша **Alt+Shift+D** (меняется в `about:addons` → ⚙ → «Управление горячими клавишами») и пункт меню «Скачать сразу» качают без окон; по завершении приходит уведомление. Стрелка рядом с кнопкой (в Shorts — правый клик) открывает эти настройки снова.
- **Несколько ссылок:** вставьте список (можно с мусором вокруг, ссылки найдутся сами). Загрузки идут в очереди; число одновременных (1–4) задаётся в «Настройках».
- **Плейлисты:** ссылка на плейлист или кнопка «Весь плейлист…» у видео из плейлиста открывает список роликов с галочками; можно сохранять в отдельную папку с названием плейлиста (первые 300 роликов).
- Новая иконка.

Обновление: закройте Firefox → замените файлы → `update.ps1` (помощник v7) → `sign.ps1` → установите новый `.xpi` поверх старого. Firefox спросит новое разрешение (доступ к youtube.com для кнопки).
